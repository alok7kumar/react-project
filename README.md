# Online Shopping Web App

This is an online shopping web app built with React.js. The app includes various features such as adding products, viewing products, updating product records, and managing the user dashboard. It has a responsive layout with a header and footer, and it provides routes for easy navigation between pages.

## Features

- **Home Page**: A landing page showcasing featured products and offers.
- **About Page**: Information about the app and its creators.
- **Contact Page**: A page with contact information and a form for users to get in touch.
- **Authentication**: User registration and login functionality.
- **Dashboard**: A personalized user dashboard where users can manage their product records.
- **Add Product**: Users can add new products to the database.
- **View Products**: Browse and view all available products.
- **Update Product**: Update details of existing products.
- **Responsive Layout**: The app has a header and footer layout with a responsive design that adjusts to various screen sizes.
- **Routing**: The app uses React Router for smooth navigation between different pages.

## Tech Stack

- **React.js**: Frontend framework for building the user interface.
- **React Router**: For managing routes and navigation within the app.
- **React Toastify**: For displaying notifications to users.
- **CSS/Bootstrap**: For styling the app and ensuring responsiveness.
- **JavaScript (ES6+)**: For writing the logic and functionality.

## Installation

1. Clone the repository:

   git clone https://github.com/yourusername/online-shopping-web-app.git

2. Navigate to the project directory:

   cd online-shopping-web-app

3. Install dependencies:
    
    npm install

4. Start the development server:

    npm start


## Dependencies

**react**: React.js library for building the user interface.

**react-router-dom**: For routing and navigation between pages.

**react-toastify**: For displaying notifications to the user.

**bootstrap**: CSS framework for building responsive layouts.
